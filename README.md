## 📋 Реализованный функционал
1. `FindBook(id int) *Book` — поиск книги с возвратом указателя для изменения количества доступных экземпляров.
2. `BorrowBook(book *Book, readerID int) error` — проверка доступности, регистрация выдачи, уменьшение счетчика `Available` и защита от повторной выдачи одной и той же книги читателю.
3. `ReturnBook(book *Book, readerID int) error` — возврат книги с валидацией (нельзя вернуть книгу, которую читатель не брал).
4. `SearchBooks(query string) []Book` — поиск по названию или автору.
5. `GetStatistics()` — расчет общего фонда, доступных и выданных книг, а также определение самой популярной книги по счетчику выдач.
